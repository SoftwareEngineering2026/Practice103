Описание:
Учебный проект для получения практического опыта анализа и рефакторинга существующего программного кода. В проекте представлены реализации на нескольких языках программирования. Для работы был выбран Python-модуль FundingRaised.

Стек технологий:

Python
CSV
Git
GitHub
2. Принципы рефакторинга

В работе использовался принцип DRY (Don't Repeat Yourself).

Основная проблема исходного участка кода заключалась в дублировании логики фильтрации данных. Для каждого поля (company_name, city, state, round) использовался практически одинаковый блок кода.

Для устранения дублирования общая логика была вынесена в отдельный метод _filter_rows().

Также соответствие названий полей индексам CSV было вынесено в словарь FILTER_FIELDS.

3. Описание выполненного рефакторинга
Обнаруженные проблемы

В классе FundingRaised была обнаружена повторяющаяся логика фильтрации CSV-данных.

Для каждого параметра использовался отдельный блок с циклом и условием. Это увеличивало объём кода и усложняло его изменение и поддержку.

Кроме того, индексы CSV-столбцов были непосредственно записаны в нескольких местах программы.

Выполненные изменения

Был создан словарь FILTER_FIELDS, содержащий соответствие имени поля и индекса CSV:

FILTER_FIELDS = {
    'company_name': 1,
    'city': 4,
    'state': 5,
    'round': 9
}

Общая логика фильтрации была вынесена в метод:

_filter_rows()

После этого метод where() был упрощён и использует общий механизм фильтрации.

Метод find_by() также был упрощён за счёт использования единого соответствия полей и индексов, при этом его исходное поведение было сохранено.

Тестирование

До и после рефакторинга были запущены существующие тесты проекта.

Также были добавлены тесты для _filter_rows(), проверяющие:

фильтрацию по нескольким параметрам;
поведение при отсутствии параметров фильтрации.

Все тесты проходят успешно.


5. Вывод

В результате рефакторинга была устранена часть дублирования кода в классе FundingRaised.

Общая логика фильтрации была вынесена в отдельный метод, а соответствие полей CSV и их индексов централизовано.

При этом существующая функциональность программы была сохранена и подтверждена тестами.

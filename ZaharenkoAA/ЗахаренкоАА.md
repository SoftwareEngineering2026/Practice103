Проект: GildedRose-Refactoring-Kata

Ссылка на репозиторий: https://github.com/emilybache/GildedRose-Refactoring-Kata

Краткое описание: Предоставляется "легаси-код" системы инвентаризации магазина, который необходимо улучшить, не изменяя его внешнего поведения.

Стек технологий: Python, стандартная библиотека unittest для модульного тестирования, фреймворк ApprovalTests для утверждений (approval tests)

Принципы рефакторинга:
Extract Method – разбиваем большой метод на несколько маленьких.
Eliminate Duplication – выносим повторяющиеся проверки в отдельные функции или переменные.
Single Level of Abstraction – основной метод должен читаться как последовательность шагов.

Обнаруженные проблемы:
Длинный метод
Глубокая вложенность
Дублирование кода
Жёсткая привязка к именам

Решения:
Длинный метод разбит на несколько коротких методов
Глубокая вложенность каждый метод содержит только один уровень условий
Дублирование кода проверка quality < 50 теперь выполняется только в соответствующих методах
Жёсткая привязка к именам теперь для добавления нового типа достаточно добавить метод и условие в _update_item – изменения локализованы

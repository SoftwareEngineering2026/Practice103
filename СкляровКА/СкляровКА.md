# Лабораторная 3. Рефакторинг

В textlab-project уже создана настоящая история: main содержит исходную реализацию,
refactor-analysis содержит отдельный коммит рефакторинга. Diff между ветками меняет
только textlab/analysis.py. Все 21 тест проекта прошли и до, и после изменения.
Pull request с рефакторингом: https://github.com/dyda5505-cloud/textlab-course/pull/1. Репозиторий: https://github.com/dyda5505-cloud/textlab-course.

Выбран собственный проект TextLab (соседняя папка textlab-project).
До рефакторинга: before.py — ручной подсчёт частот, отдельный цикл формирования ответа,
регулярное выражение встроено в основную функцию.
После: after.py — выделена tokenize, шаблон вынесен в именованную константу,
Counter заменяет ручное управление словарём, ответ строится comprehension.
Сортировка (-частота, слово), casefold, предел top-10 и схема результата сохранены.

Проверка: `python -m pytest lab03 --cov=after --cov-report=term-missing`
из корня комплекта. Девять тестов сравнивают обе версии, включая 2401 комбинацию токенов.
Для сдачи создать в личном проекте отдельную ветку: сначала добавить before.py и тесты,
затем отдельным коммитом заменить реализацию на after.py. Создать PR с этим изменением.
Не выдавать один итоговый снимок файлов за историю рефакторинга.
